# Forfaits Cameroun V1

PWA statique pour comparer les forfaits Internet au Cameroun.

## Déploiement Render
Créer un **Static Site** avec :
- Build command : `echo "No build required"`
- Publish directory : `public`

Un `render.yaml` est fourni pour Blueprint.

## Données
La V1 contient les offres Home Infinity et Giga Box publiées par Orange Cameroun au moment de la création. Les données sont dans `public/index.html` et peuvent être mises à jour sans backend.

## Important
L'application ne promet pas un accès Internet illimité par contournement. Elle affiche uniquement des offres commerciales et renvoie vers les sources officielles.
